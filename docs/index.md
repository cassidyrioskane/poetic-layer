# Poetic Layer

## Overview
Poetic Layer is a creative software application that helps users define, organize, and evaluate motifs and mappings for text-based projects. It allows you to:

- Store and view **motifs** (individual text units with metadata)
- Create and manage **mappings** (relationships and rules between motifs)
- Track outputs and results in a **ledger**

The application has a **frontend** (React) for user interaction and a **backend** (FastAPI) for data management.
